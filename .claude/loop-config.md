# loop-config

`loop-engineering` / `loop-engineering-status` スキルが読む、このリポジトリ固有の設定。
キーの意味と、書かなかった場合の推定のしかたは
`.claude/skills/loop-engineering/references/config.md` を参照。

**確定方針の正は `BACKLOG.md` と `.cursor/rules/`。** ここにあるのは、スキルが手順を
分岐させるための値だけで、規約そのものではない。食い違ったら規約側に従い、
食い違っていること自体を報告する。

（`AGENTS.md` は HeroUI React v3 のドキュメント索引であって、開発規約ではない。
ただし HeroUI を触る作業では、記憶に頼らず必ずそこから docs を引くこと。）

| キー | 値 |
| --- | --- |
| rules_file | BACKLOG.md |
| backlog | BACKLOG.md（進捗の正は Issue #13。#13 を更新できない場合は BACKLOG.md が正） |
| default_branch | main |
| branch | feature/<short-kebab>-<短いランダム>（接尾辞は実行ごとに変える。例 `openssl rand -hex 2`） |
| verify | npm run lint && npm run fmt:check（JS/TS を触ったとき。テストのある変更は `npm test` も） |
| format | npm run fmt |
| evidence | screenshot |
| screenshot_viewport | 390x844（iPhone 16） |
| mutation_test | off |
| review_style | heading-markers |
| review_markers | `## コードレビュー結果`, `## セキュリティレビュー結果`, `セキュリティレビュー完了`, `_Generated by [Claude Code]` を含むコメント |
| severity | [Major], [Minor]（どちらも直す） |
| review_wait | 10m |
| halt | report-issue |
| report_prefix | [loop-report] |
| halt_prefix | [loop-halt] |
| halt_file | .cursor/loop/HALT |
| stack_limit | 5 |
| retry_limit | 2 |
| draft_pr | never |

## 補足

- **確定スタック**: React + TypeScript + Vite + Tailwind CSS v4 + HeroUI React v3 + Effect。
  リンタ oxlint、フォーマッタ oxfmt、公開は GitHub Pages。
  **サーバ・Expo・HeroUI Native は使わない。** これを覆す必要が出たらユーザー判断（着手しない）
- **サイクルの正は Issue #3**: 作業25分 → 短い休憩5分 → 作業25分 → 長い休憩15分、終了で自動遷移。
  分数設定画面やスキップボタンを勝手に足さない
- 依存の追加・更新は `.cursor/rules/npm-package-age.mdc`（リリースから7日以上経った安定版の
  最新、exact pin）。版は `node scripts/npm-stable-version.mjs <pkg>` で決める
- レビュー判定は**見出しと帰属フッターで行う。投稿者の login では判定しない**
  （リポジトリオーナー名義で投稿されることがある）
- 停止フラグは `.cursor/loop/HALT` の**存在だけ**で判定する（空でも halt）
- 既存の `.cursor/skills/loop-engineering/` は Cursor 用の同等スキル。
  スクリプト（`loop-gate.sh` / `unaddressed_reviews.py`）はそちらにもある
